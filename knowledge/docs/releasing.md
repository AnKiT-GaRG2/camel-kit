# Releasing Camel Kit Knowledge

Knowledge is released independently from the Camel Kit monorepo. Follow the
[shared release guide](../../docs/releasing.md) for parent and product versioning,
Maven staging, release approval and maintainer-triggered index publication.

The standalone repository's former release procedure does not apply to current
monorepo sources. In particular, index discovery uses `knowledge-index-v1-*` tags
and does not depend on which GitHub release is marked latest.
